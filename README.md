# F_Ccfolia-PSD-Studio
코코포리아 맵세팅 zip, psd 레이어 등을 한번에 보정하고 추출 할 수 있도록 합니다.
이미지, psd, zip(코코포리아에서 생성된) 불러오면 실제 사용하는 것 과 유사하게 배치되고 한번에 색을 변경시킵니다.
오른쪽 패널을 통해 이미지들의 미리보기를 on/off 할 수 있습니다.
apng 의 경우 코코포리아의 최대 용량크기는 5mb 에 맞춰서 가장 손실이 적은 형태로 용량이 최소화됩니다.
apng 로 저장 하실 때 루프 설정을 확인해주세요. 업로드 이후 apng 의 움직임이 멈춰있거나 하면 루프 설정을 잘 못 하신겁니다.
